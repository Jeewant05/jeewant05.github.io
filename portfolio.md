> Data Analyst & Computer Engineer · M.S. Computer Engineering @ Virginia Tech

## Running Locally

Clone the repo and open the file directly — no server or install needed:

```bash
git clone https://github.com/Jeewant05/jeewantc.github.io.git
cd jeewantc.github.io
open index.html      # or just double-click it
```

## Deploying (GitHub Pages)

1. Push `index.html`, `profile.jpg`, and `resume.pdf` to the repository root.
2. Go to **Settings → Pages**.
3. Set **Source** to *Deploy from a branch*, **Branch** to `main`, folder `/(root)`.
4. Save and wait about a minute — the site goes live at `https://jeewantc.github.io`.
